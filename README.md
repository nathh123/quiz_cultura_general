# quiz_cultura_general
Este código muestra un juego el cual es un quiz de preguntas de cultura general, cuando aciertas a la pregunta este te suma 10 puntos y si te equivocas te resta una vida pero mantienes tu puntaje. 
*Cómo ejecutar el programa
1. Instala Python.
2. Descarga `quiz.py` y `preguntas.json` y guárdalos en la misma carpeta.
3. Abre una terminal en esa carpeta y ejecuta:
   python quiz.py
